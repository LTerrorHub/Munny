# Munny Matrix 2.0 — Android nativo

Projeto em Kotlin + Jetpack Compose para o aplicativo Munny. Inclui o motor financeiro corrigido, cinco abas, gráficos dinâmicos, efeito Matrix e controle de privacidade dos saldos.

O projeto está em implantação. Nunca envie dados financeiros, senhas ou chaves Supabase secretas para este repositório.
